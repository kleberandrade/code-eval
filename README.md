# CodeEval Solutions

![Language: C](https://img.shields.io/badge/Language-C-555555)

C programming solutions to CodeEval exercises.

## Getting started

- Each C exercise is a separate program. Compile and run one source file at a time with a compatible C compiler, providing the problem input on standard input.

- Do not compile all exercise files into one executable: independent solutions may each define `main`.
